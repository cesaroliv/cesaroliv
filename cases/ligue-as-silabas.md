# Ligue as Sílabas

**Status:** concluído.

## Produto
Jogo educativo web para associação de sílabas, concebido para funcionar bem em dispositivos móveis e oferecer uma experiência simples para crianças.

## Tecnologias e recursos
- JavaScript
- Phaser
- Vite
- interface mobile-first
- fases progressivas
- áudio/TTS em português
- feedback visual
- persistência local de progresso
- publicação web

## Relação com Aprender Brincando
O jogo é uma entrega completa por si só e também serve como primeira experiência do conceito maior **Aprender Brincando**, plataforma que permanece em desenvolvimento.

## Competências demonstradas
- entrega de aplicação interativa
- lógica de jogo
- UX responsiva
- manipulação de estado
- áudio e feedback
- build e publicação
