# Aprender Brincando

**Status:** plataforma maior em desenvolvimento. O jogo **Ligue as Sílabas** é uma entrega independente já concluída.

## Visão
Plataforma educacional planejada para reunir cerca de 20 experiências/jogos educativos em uma arquitetura comum.

## Fundação já construída
- Next.js / React / TypeScript
- Supabase
- autenticação e autorização
- conteúdo versionado
- persistência de sessões
- resultados confirmados pelo servidor
- game core compartilhado
- quiz e matching
- relatórios de acompanhamento
- testes unitários, integração, banco e E2E
- Playwright e acessibilidade
- migrations verificadas e scanner de segredos

## Estado

O projeto avançou por múltiplos milestones e possui uma base técnica robusta, mas permanece **não público e em desenvolvimento**. Não é apresentado como plataforma finalizada.

## Competências demonstradas
- arquitetura incremental
- QA desde a especificação
- modelagem e persistência
- autorização e segurança
- testes E2E e acessibilidade
- documentação técnica
- desenvolvimento orientado a milestones

## Aplicação freelance
Relevante para **EdTech, aplicações web, QA, Playwright, Supabase, Next.js, sistemas com autenticação e projetos que precisam de boa documentação e critérios de aceite**.
